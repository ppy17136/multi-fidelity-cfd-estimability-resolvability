# Original precomputation sources

diffusion_precomputation.zip retains the original two source files byte for
byte. Their hashes are checked against stochastic_diffusion/results/FREEZE.json.
They document the specification and generator used before incorporation of
the diffusion results. These are provenance records, not current usage
instructions. Use the main README and stochastic_diffusion/PROTOCOL.md for
the present workflow. Original source records have not been rewritten.
