# Version 2.1.8

Common-partition manuscript outputs and robust-union auxiliary analyses now
have separate locations, explicit names, and separately grouped verification.
The default verifier reconstructs only manuscript-related results; the optional
robust-union flag adds all four auxiliary builders. Four release-routing tests
check separation. Numerical algorithms, original source vectors, figures, and
all relocated auxiliary numerical payloads are unchanged. The algorithm-table
CSV changes one descriptive word only. This release has no assigned public DOI.
