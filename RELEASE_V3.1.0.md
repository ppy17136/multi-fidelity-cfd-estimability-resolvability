# Version 3.1.0 verification records

Version DOI: <https://doi.org/10.5281/zenodo.23112322>.

Use the attached `MCS_Verification_Records_v3.1.0.zip` aggregate, not the
automatically generated repository source ZIP. Extract into a fresh directory
and run `python verify_all.py`. Seven saved-record suites are checked;
this is not an end-to-end raw CFD rerun.

The collection unifies conditional-risk, input-stability, four-cell,
matched-native, fine-diagnostic, six-cell, and certificate-hierarchy
verification archives. All seven numerical archive hashes match the freshly
verified record packages. DOI-specific citation metadata and the outer manifest
identify this exact distribution. The earlier public deposits remain intact.

Six numerical archives are byte-identical to their preceding verified
packages. The input-stability archive contains a documented distribution-only
protocol revision and corresponding verifier metadata; scientific inputs,
generating code, and numerical results are unchanged.

Code is MIT; authored numerical data and documentation are CC BY 4.0.
The asset contains no manuscript text, submission correspondence, private
reviews, restricted physical-experiment data, or third-party articles.
Probabilities and costs are conditional pathway diagnostics and declared
identity-release weights, not physical risk or measured CFD acquisition costs.
